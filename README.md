# Alan Sobchacki: personal website

My personal website. Plain HTML and CSS, with no framework, build step or JavaScript.

- `index.html`: the page content
- `style.css`: styles, including light/dark themes (the toggle is a CSS-only checkbox)
- `assets/`: photo and project images

To preview it locally, open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```

To deploy, upload the repo as-is to any static host.
